# AmazonPrime-TVShows-Movies-EDA-Project 📊| Power BI


## 📌 Project Overview

The **Amazon Prime Content Analysis Dashboard** is an interactive Power BI dashboard designed to analyze and visualize Amazon Prime movies and TV shows.

The dashboard provides insights into content distribution, audience popularity, IMDb votes, genres, actors, runtime, geographic distribution, and content release trends over the years.

The objective of this project is to transform raw streaming-content data into meaningful visual insights that can support content analysis and data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows available on Amazon Prime.
- Identify the most popular titles based on IMDb votes.
- Analyze the most popular actors based on total popularity.
- Understand genre distribution using average TMDB popularity.
- Analyze the distribution of content runtime.
- Explore content availability across different countries.
- Identify trends in Movies and TV Shows released over the years.
- Build an interactive dashboard for dynamic data exploration.

---

## 📈 Dashboard Overview

The dashboard contains the following key sections:

### 1. Content Summary

The dashboard provides high-level KPIs for:

- **Total Shows:** 1,355
- **Total Movies:** 8,416

These KPIs provide a quick overview of the content distribution.

### 2. Top 5 Actors by Total Popularity

This visualization identifies the top actors based on their total popularity score.

Example:

- Derek Drymon

The visualization helps identify actors associated with highly popular content.

### 3. Top 5 Titles by IMDb Votes

This chart highlights the titles receiving the highest number of IMDb votes.

The dashboard displays:

- IMDb vote count
- Movie/Show title
- Ranking of top titles

### 4. Top 10 Genres by Average TMDB Popularity

A donut chart is used to analyze genres based on average TMDB popularity.

The dashboard includes genres such as:

- Animation
- Fantasy
- Sci-Fi
- Family
- Thriller
- Action
- War

This provides an overview of audience interest across different content categories.

### 5. Runtime Distribution

A histogram visualizes the distribution of content runtime.

This helps identify:

- Common runtime ranges
- Short-form content
- Long-form content
- Overall runtime patterns

### 6. Global Content Distribution

A geographic map visualizes Amazon Prime content distribution across countries.

This helps understand the global availability and distribution of streaming content.

### 7. Trend of Movies and Shows Released Over the Years

A time-series visualization analyzes the number of Movies and TV Shows released across different years.

This helps identify:

- Historical content growth
- Changes in Movie and TV Show production
- Periods of increased content releases
- Long-term streaming content trends
